# Reporting security issues

This repository is a local testing application. See [the security model](docs/SECURITY.md) and [known production gaps](docs/ROADMAP.md).

Do not post credentials, private documents, reset links, access tokens or exploit details involving real accounts in a public issue. If GitHub private vulnerability reporting is enabled for this repository, use its Security tab. Otherwise arrange a private reporting channel with the repository owner before sharing sensitive details.

Reports should identify the affected version, impact, minimal synthetic reproduction and suggested remediation. No security certification or response-time guarantee is claimed.
